# Le Test Civique

build a site for do the french test Examen civique, this is the site with all the content and big subjects of the test https://formation-civique.interieur.gouv.fr/fiches-par-thematiques/ , The student has to reach 80% of the test, 32 questions out of 40, it has to be a tool that help to train, improve every day, repeat and train as much as possible before the test. It could be split it by day or 15 minutes par day or by big subjects (there are 5 big subjects), what do you propose before build?
my plan 
A web-based interactive training tool that includes:

All three training modes (daily, theme-based, mock exams)
Personalized dashboard
Mobile-responsive design (practice anywhere)
French language interface
Ability to save progress and continue later
